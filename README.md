## 🚨 Critical Points

1. **Separate Systems:** Kifayah VAT ≠ Muslim Welfare AI
2. **Multilingual First:** Support 6 languages natively (not translations)
3. **Agentic AI:** Use LangGraph for multi-agent orchestration
4. **Offline-First:** IndexedDB + service worker (works without internet)
5. **Field-Tested:** 30-min surveys > 2-hour manual
6. **Ethical:** DPDP Act compliance, informed consent, data minimisation
7. **Data-Driven:** Pre-2007 vs post-2007 comparison (evidence-based policy)
